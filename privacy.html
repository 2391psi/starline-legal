This Privacy Policy (\"Policy\") describes what data the Starline application (\"the App\") processes when used, and how such data is stored and used. By using the App, the User agrees to the terms of this Policy.

1. GENERAL PROVISIONS

The App does not require account registration and does not collect data that identifies the User, except for the anonymized purchaser identifier used solely to protect the free trial period (see Section 6). The App does not include analytics, usage-statistics collection, or advertising-network integrations.

2. DATA STORED ON THE USER'S DEVICE

The App stores the following data exclusively in the local storage of the User's device. The Developer has no access to this data and does not transmit it to any third-party server:

  • SMB, NFS, and WebDAV server connection settings (addresses, credentials) entered by the User;
  • media playback history and position;
  • App settings (interface language, subtitle appearance, buffering parameters, and other user preferences);
  • cached artwork and descriptions for media content.

Uninstalling the App permanently deletes the data listed above. The App does not synchronize or back up this data to any cloud service.

3. DATA THE APP DOES NOT COLLECT

The App does not: collect analytics or usage statistics; transmit crash reports to third parties; collect data for targeted-advertising purposes; access the device's contacts, location, camera, or microphone; transfer or sell User data to third parties.

4. NETWORK CONNECTIONS

The App establishes network connections only to resources specified by the User: the User's own servers (SMB, NFS, WebDAV) and direct links to video resources opened at the User's initiative. The Developer has no access to the content of such traffic.

5. USE OF THETVDB

To identify the User's media, the App sends TheTVDB the title extracted from a file name and, when available, the year and media type. TheTVDB may return titles, descriptions, genres, runtime, studios, credits, seasons, episodes, external identifiers, content ratings, and artwork. The App does not send media files, server credentials, playback history, or payment information to TheTVDB.

Metadata provided by TheTVDB. Please consider adding missing information or subscribing.

6. PROTECTION AGAINST FREE TRIAL REUSE

To protect the free trial, the App sends the Developer's server a pseudonymous platform identifier and the trial start date once. When the full Amazon version is purchased or restored, the App sends the Amazon user ID, product ID, and receipt ID to the server once. The server validates the receipt through Amazon Receipt Verification Service and stores only irreversible identifier hashes and the verification time. The User's name, email address, and payment information are not transmitted. After successful verification, the permanent entitlement is stored locally and normal launches require neither the server nor an Internet connection. One online restore may be required after uninstalling the App or clearing its data.

7. THIRD-PARTY OPEN-SOURCE LIBRARIES

The App uses a number of third-party open-source components; the full list, their versions, and licenses are available in the App at Settings → About → Open Source Licenses. Two of these components are distributed under the GNU Lesser General Public License (LGPL) version 2.1 or later: FFmpeg (libavcodec, libavutil, libswresample), used as a fallback software decoder for certain audio tracks (AC-3, E-AC-3, DTS, TrueHD) on devices whose hardware decoder does not support them — source code available at https://ffmpeg.org/; and jcifs-ng, used as part of the SMB network client — source code available at its public repository. Starline is not affiliated with the FFmpeg project or the jcifs-ng project.

8. PERMISSIONS REQUESTED

INTERNET — establishing network connections to resources specified by the User.
ACCESS_NETWORK_STATE, ACCESS_WIFI_STATE — verifying network availability before starting streaming playback.
CHANGE_WIFI_MULTICAST_STATE — discovering network servers (SMB/WebDAV/NFS) on the local network when the User initiates a server search.
READ_MEDIA_VIDEO, READ_MEDIA_AUDIO (READ_EXTERNAL_STORAGE on older Android versions) — accessing the list and content of media files stored on the device.
WAKE_LOCK, FOREGROUND_SERVICE, RECEIVE_BOOT_COMPLETED — running the background media-library scan (indexing files added by the User) without keeping the app's main screen open.
com.android.vending.BILLING (Google Play build only) — processing the in-app purchase through Google Play Billing.

9. RESPONSIBILITY FOR CONTENT

The App is a general-purpose media player and does not host, index, or provide media content. The sources to which the User connects, and the content the User chooses to play, are determined solely by the User, who bears full responsibility for compliance with applicable law.

10. CHILDREN

The App is not directed at children and does not knowingly collect data from users of any age, except for the anonymized identifier described in Section 6 of this Policy.

11. CHANGES TO THIS POLICY

The Developer may update this Policy from time to time. The current version is published in the corresponding section of the App together with its effective date. Continued use of the App after such changes constitutes acceptance of the updated Policy.
